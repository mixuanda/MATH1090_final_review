\chapter{Big sets}

本章研究 set 的大小。有限集合可以数出元素个数；无限集合则需要用
function 比较大小。核心语言是 bijection, injection, cardinality,
Cantor--Bernstein theorem, Cantor's theorem, Axiom of Choice, Zorn's
Lemma, density, and well-ordering。写证明时要分清两件事：一个 set 是否
可以 enumerate，是 cardinality 的问题；一个 subset 是否在 real line 中到处
都能逼近，是 order and metric structure 的问题。

\section{Cardinality}

\begin{definition}[same cardinality]
设 \(X,Y\) 是 sets。若存在 bijection \(f:X\to Y\)，就说 \(X\) 与
\(Y\) have the same cardinality，记作
\[
  \card{X}=\card{Y}.
\]
这里的 bijection 同时要求 injective and surjective：每个 \(x\in X\)
对应唯一的 \(Y\)-element，并且每个 \(Y\)-element 都被某个 \(x\) 命中。
\end{definition}

\begin{definition}[finite, countable, uncountable]
设 \(X\) 是 set。若存在 \(n\in\N\) 使得 \(\card{X}=\card{n}\)，则
\(X\) is finite；此时通常写 \(\card{X}=n\)。若 \(X\) is finite 或
\(\card{X}=\card{\N}\)，则 \(X\) is countable。不是 countable 的 set
称为 uncountable。
\end{definition}

\begin{reviewbox}{Cardinality proof language}
Cardinality proof 不是比较长度、面积、density 或 visual size，而是比较
functions。要证明 \(\card{X}\leq\card{Y}\)，写出 injection
\(X\to Y\)，并解释不同 inputs 为什么不会撞到同一个 output。要证明
\(X\) is countable，可以给出 enumeration \(x_0,x_1,\ldots\)，也可以给出
surjection \(\N\to X\)。要证明 uncountable，通常假设存在 enumeration，
然后用 diagonal argument 构造一个不在 list 中的 object。
\end{reviewbox}

\begin{reviewbox}{How to prove equal cardinality}
证明 \(\card{X}=\card{Y}\) 有两条常用路线。第一条是直接构造
bijection \(X\to Y\)，然后分别验证 injectivity and surjectivity。第二条
是分别构造 injections \(X\to Y\) and \(Y\to X\)，再引用
Cantor--Bernstein theorem。第二条在处理 intervals 和删去少数点的
uncountable sets 时尤其方便。选择路线时先看哪一边更容易嵌入另一边：若
两个 sets 本来就互相包含在某个 ambient set 中，Cantor--Bernstein 往往比
写 explicit bijection 更稳；若题目要求 enumeration，则应给出具体顺序或
formula。
\end{reviewbox}

\subsection{Countable examples}

\begin{exerciseblock}[Lecture Notes Exercise 62]
Prove that \(\card{\N}=\card{\Z}\).
\end{exerciseblock}

\begin{solution}
本讲义采用 \(\N=\{0,1,2,\ldots\}\)。定义 \(f:\N\to\Z\) 为
\[
  f(0)=0,\qquad
  f(2k+1)=k+1,\qquad
  f(2k+2)=-(k+1)
  \quad (k\in\N).
\]
这个 function 将 natural numbers 依次送到
\[
  0,1,-1,2,-2,3,-3,\ldots .
\]
先证明 \(f\) is injective。若 \(f(n)=0\)，由定义只能有 \(n=0\)。
若 \(f(n)>0\)，则 \(n\) 必为 \(2k+1\)，且 \(f(n)=k+1\) 决定了
\(k\)，从而决定了 \(n\)。若 \(f(n)<0\)，则 \(n\) 必为 \(2k+2\)，且
\(f(n)=-(k+1)\) 也决定了 \(k\)，从而决定了 \(n\)。正整数、负整数和
\(0\) 三类 image 互不重叠，所以不同的 input 不会有相同 image。

再证明 \(f\) is surjective。取任意 \(z\in\Z\)。若 \(z=0\)，则
\(z=f(0)\)。若 \(z=m>0\)，其中 \(m\in\N\) 且 \(m\ge 1\)，则
\[
  z=m=f(2m-1).
\]
若 \(z=-m<0\)，其中 \(m\ge 1\)，则
\[
  z=-m=f(2m).
\]
每个 integer 都出现在 \(f\) 的 image 中。因此 \(f\) is bijective，
所以 \(\card{\N}=\card{\Z}\)。
\end{solution}

\begin{explanation}
这个 proof 的重点不是说两个 infinite sets ``一样多''，而是给出一条
明确的 enumeration。正整数和负整数若分别排在两段，负整数永远等不到；
交替列出 \(1,-1,2,-2,\ldots\) 可以保证每个 integer 在有限步内出现。
类似证明中，surjectivity 的检查必须覆盖 \(0\)、positive integers 和
negative integers 三类；injectivity 的检查则要说明这三类 images 互不重叠。
只写出前几项 pattern 不足以成为 proof，必须把第 \(m\) 个正整数和第
\(-m\) 个负整数对应到明确的 natural number。
\end{explanation}

\begin{exerciseblock}[Worksheet 8 Exercise 1]
Prove that \(\card{\Z}=\card{\N}\).
\end{exerciseblock}

\begin{solution}
由 Lecture Notes Exercise 62 已构造 bijection \(f:\N\to\Z\)。bijection
有 inverse function \(f^{-1}:\Z\to\N\)，而 inverse of a bijection 仍是
bijection。因此 \(\card{\Z}=\card{\N}\)。

若要写出 explicit formula，可以定义
\[
  g(z)=
  \begin{cases}
    0,&z=0,\\
    2z-1,&z>0,\\
    -2z,&z<0.
  \end{cases}
\]
由 Lecture Notes Exercise 62 中的 \(f\) 可见 \(g=f^{-1}\)，所以
\(g\) is bijective。
\end{solution}

\begin{explanation}
Worksheet 8 Exercise 1 与 Lecture Notes Exercise 62 是同一个 cardinality
statement，只是等号两边顺序相反。cardinality equality 是 symmetric：
若 \(X\) 与 \(Y\) 之间有 bijection，则把箭头反过来得到 \(Y\) 与 \(X\)
之间的 bijection。
因此处理反向 statement 时不要重新设计 enumeration，先检查上一题的
bijection 是否已经有 inverse。若写 explicit inverse，最安全的方法是按
output 的类别分 cases，并代回原 function 验证 \(f(g(z))=z\) and
\(g(f(n))=n\)。
\end{explanation}

\begin{theorem}[\(\Q\) is countable]
Rational numbers 组成 countable set。
\end{theorem}

\begin{proof}
先处理 positive rationals。把每个 positive rational 写成 lowest terms
\(p/q\)，其中 \(p,q\in\N\) 且 \(p,q\ge 1\)。将 pair \((p,q)\) 放在
infinite grid 的第 \(p\) 行第 \(q\) 列，然后按 diagonal
\[
  p+q=2,\quad p+q=3,\quad p+q=4,\ldots
\]
依次扫描。每条 diagonal 上只有有限多个 pairs；每个 pair \((p,q)\)
属于唯一的 diagonal \(p+q\)。扫描时只记录 lowest terms 的 fractions，
跳过不是 lowest terms 的重复写法，就得到 \(\Q^+\) 的 enumeration。

最后将
\[
  \Q=\{0\}\cup \Q^+\cup(-\Q^+)
\]
按 \(0,q_1,-q_1,q_2,-q_2,\ldots\) 交错排列。于是 \(\Q\) is countable。
\end{proof}

\begin{explanation}
diagonal argument 在这里解决的是 ``每一行无限长'' 的问题。若逐行扫描，
第一行永远不会结束；按 \(p+q\) 扫描时，第 \(s\) 条 diagonal 只有
\(s-1\) 个 pairs，因此可以在有限时间内进入下一条 diagonal。
解决 ``countable union of countable-looking objects'' 时，可以先把对象编码
成 \(\N\times\N\)，再用 diagonal enumeration。对于 rationals，分子和分母
给出 pair；对于 finite strings，可以用 length 和字典序位置给出 pair。重复
表示不会破坏 countability，因为跳过重复项仍然留下一个 enumeration。
\end{explanation}

\subsection{Cardinal inequalities and Cantor--Bernstein}

\begin{definition}[cardinal inequality]
设 \(X,Y\) 是 sets。若存在 injection \(f:X\to Y\)，则写
\[
  \card{X}\le \card{Y}.
\]
若 \(\card{X}\le\card{Y}\) 且 \(\card{X}\ne\card{Y}\)，则写
\(\card{X}<\card{Y}\)。
\end{definition}

\begin{theorem}[Cantor--Bernstein theorem]
若存在 injections \(f:X\to Y\) and \(g:Y\to X\)，则存在 bijection
\(h:X\to Y\)。换言之，
\[
  \card{X}\le\card{Y}
  \quad\text{and}\quad
  \card{Y}\le\card{X}
  \quad\Longrightarrow\quad
  \card{X}=\card{Y}.
\]
\end{theorem}

\begin{explanation}
Cantor--Bernstein theorem 允许我们避免寻找 complicated explicit
bijection。很多时候，两个 injections 很容易构造：例如 inclusion 给出
\((0,1)\to[0,1]\)，linear compression 给出 \([0,1]\to(0,1)\)。theorem
保证这已经足以证明 equal cardinality。

它的 proof idea 是把 \(X\) 中的 elements 分成几类：有些 elements 应该沿
\(f:X\to Y\) 前进，有些 elements 应该沿 \(g^{-1}\) 从 \(X\) 回到 \(Y\)。
分类依据不是任意选择，而是看一个 element 是否位于由
\(X\setminus g(Y)\) 出发、反复应用 \(g\circ f\) 得到的 chains 上。这样定义
出来的 map 会在每条 chain 上使用同一个方向，避免两个 different elements
被送到同一个 \(Y\)-element，也避免漏掉某些 \(Y\)-elements。练习中的错误
formula 往往就是在 stable part 或 chain part 上用错方向。
\end{explanation}

\begin{exerciseblock}[Homework 9 Problem 3]
Cantor--Bernstein struggles. Let \(X,Y\) be two sets. Let \(f:X\to Y\) and
\(g:Y\to X\) be injections. Define \(A_0=X\), \(A_{n+1}=g(f(A_n))\), and
\[
  A=\bigcap_{n\ge 0} A_n.
\]
For each proposed function in Homework 9, give an example showing that \(h\)
does not have to be a bijection.
\end{exerciseblock}

\begin{solution}
令 \(X=Y=\N\)，令 \(g=\id_{\N}\)，并定义
\[
  f(0)=0,\qquad f(n)=n+1\quad(n\ge 1).
\]
则 \(f\) is injective，因为 \(0\) 的 image 是 \(0\)，而 positive inputs
\(n\ge 1\) 的 image 是 \(n+1\)，不同 positive inputs 有不同 image。
\(g\) 也是 injection。注意 \(1\notin f(\N)\)，所以 \(f\) is not
surjective。

在这个例子中，
\[
  A_0=\N,\qquad
  A_n=\{0\}\cup\{n+1,n+2,n+3,\ldots\}\quad(n\ge 1),
\]
因此
\[
  A=\bigcap_{n\ge 0}A_n=\{0\},
  \qquad
  A_n\setminus A_{n+1}=\{n+1\}\quad(n\ge 0).
\]

对 Homework 9 Problem 3(a)，proposed map 在 \(A_n\setminus A_{n+1}\)
以及 \(A\) 上都使用 \(f\)。这些 pieces 覆盖整个 \(X=\N\)，所以
\[
  h(n)=f(n)\quad\text{for all }n\in\N.
\]
因此 \(h(\N)=\{0,2,3,4,\ldots\}\)，没有命中 \(1\)。于是 \(h\) is not
surjective，故不是 bijection。

对 Homework 9 Problem 3(b)，proposed map 在 \(A_n\setminus A_{n+1}\)
上使用 \(f\)，在 \(A=\{0\}\) 上使用 \(g^{-1}\)。因为 \(g=\id_{\N}\)，
有 \(g^{-1}(0)=0=f(0)\)。所以此时仍有
\[
  h(0)=0,\qquad h(n)=n+1\quad(n\ge 1).
\]
这个 \(h\) 的 image 仍为 \(\{0,2,3,4,\ldots\}\)，没有命中 \(1\)。因此
\(h\) is not surjective，故不是 bijection。
\end{solution}

\begin{explanation}
Cantor--Bernstein 的正确 proof 会精细地区分哪些 \(x\in X\) 应该用
\(f\)，哪些 \(x\in X\) 应该经由 \(g^{-1}\) 回到 \(Y\)。Homework 9 的两个
错误 formula 把 stable intersection \(A\) 处理错了。本 counterexample
让 \(A=\{0\}\)，并让 \(f\) 缺少一个 image point \(1\)，这样 proposed map
会退化成 \(f\) 或几乎退化成 \(f\)，surjectivity 立即失败。
做 ``disprove a proposed construction'' 的题时，不需要寻找复杂 sets。
先试 \(X=Y=\N\)，让其中一个 injection 是 identity，另一个 injection
故意漏掉一个 point。接着计算 proposed construction 在这个简单模型上的
实际 image。若 image 少了某个 element，就已经证明它不可能是 general
bijection。
\end{explanation}

\subsection{Products of countable sets}

\begin{exerciseblock}[Worksheet 8 Exercise 2]
Prove that \(\card{\N\times\N}=\card{\N}\).
\end{exerciseblock}

\begin{solution}
定义 Cantor pairing function
\[
  \pi:\N\times\N\to\N,\qquad
  \pi(m,n)=\frac{(m+n)(m+n+1)}{2}+n.
\]
设 \(s=m+n\)。pair \((m,n)\) 被放在第 \(s\) 条 diagonal 上，而
\[
  T_s=\frac{s(s+1)}{2}
\]
是前面所有 diagonals 的总长度。第 \(s\) 条 diagonal 中，\(n\) 从
\(0\) 到 \(s\) 区分这条 diagonal 上的 \(s+1\) 个 pairs。

若 \(\pi(m,n)=\pi(m',n')\)，令 \(s=m+n\)，\(s'=m'+n'\)。数列
\[
  T_s,T_s+1,\ldots,T_s+s
\]
恰好是第 \(s\) 条 diagonal 的 codes，并且这些 intervals 对不同的
\(s\) 两两不交。因此 \(s=s'\)。在同一条 diagonal 上，code 的最后一项
\(+n\) 决定了 \(n\)，于是 \(n=n'\)，再由 \(m=s-n\) 得 \(m=m'\)。
所以 \(\pi\) is injective。

反过来，给定 \(r\in\N\)，存在唯一的 \(s\in\N\) 使得
\[
  T_s\le r<T_{s+1}.
\]
令 \(n=r-T_s\)，则 \(0\le n\le s\)，令 \(m=s-n\)。于是
\(\pi(m,n)=r\)。所以 \(\pi\) is surjective。综上，\(\pi\) is bijective，
故 \(\card{\N\times\N}=\card{\N}\)。
\end{solution}

\begin{explanation}
这个 proof 是 diagonal enumeration 的 formula 版本。每个 pair
\((m,n)\) 有唯一的 diagonal number \(m+n\)，每条 diagonal 有有限多个
pairs，因此可以把二维 grid 排成一条 sequence。surjectivity 的关键是：
任意 natural number \(r\) 都落在唯一一个 diagonal 的 code interval 中。
解决类似 \(\N^2\)、\(\Z^2\)、\(\Q^2\) 的 countability 题时，不必画完整
grid。先把每个对象转成有限 tuple of natural numbers，再用 pairing
function 或按 coordinate sum 分层。验证时要说明每一层 finite，并且每个
对象出现在某一层；这两点合起来才给出 countable enumeration。
\end{explanation}

\begin{exerciseblock}[Homework 9 Problem 4]
Show that \(\card{\N\times\N\times\N}=\card{\N}\).
\end{exerciseblock}

\begin{solution}
由 Worksheet 8 Exercise 2，存在 bijection
\(\pi:\N\times\N\to\N\)。定义
\[
  F:\N\times\N\times\N\to\N,\qquad
  F(a,b,c)=\pi(\pi(a,b),c).
\]
先证明 \(F\) is injective。若
\[
  F(a,b,c)=F(a',b',c'),
\]
则
\[
  \pi(\pi(a,b),c)=\pi(\pi(a',b'),c').
\]
因为 \(\pi\) is injective，有 \(c=c'\) 且
\(\pi(a,b)=\pi(a',b')\)。再次使用 \(\pi\) 的 injectivity，得到
\(a=a'\) and \(b=b'\)。所以 triples 相同，\(F\) is injective。

再证明 \(F\) is surjective。取任意 \(r\in\N\)。因为 \(\pi\) is
surjective，存在 \(u,c\in\N\) 使得 \(r=\pi(u,c)\)。再次使用
surjectivity，存在 \(a,b\in\N\) 使得 \(u=\pi(a,b)\)。于是
\[
  r=\pi(\pi(a,b),c)=F(a,b,c).
\]
故 \(F\) is surjective。综上 \(F\) is bijective，因此
\[
  \card{\N\times\N\times\N}=\card{\N}.
\]
\end{solution}

\begin{explanation}
三重 product 不需要重新发明三维 enumeration。先把前两个 coordinates
\((a,b)\) pair 成一个 natural number，再把这个 number 与第三个
coordinate \(c\) pair。bijection 的 injectivity and surjectivity 在
composition 中逐层传递。
同样方法可以 induction 到任意 finite product：若 \(\N^k\) countable，则
\(\N^{k+1}\cong\N^k\times\N\cong\N\times\N\cong\N\)。注意这里是 finite
product；countably infinite product \(\N^\N\) 是另一类对象，通常会用
diagonal argument 证明 uncountable。
\end{explanation}

\section{Cantor's theorem and uncountability}

\begin{theorem}[Cantor's theorem]
对任意 set \(X\)，
\[
  \card{X}<\card{\Pow(X)}.
\]
\end{theorem}

\begin{proof}
function \(i:X\to\Pow(X)\), \(i(x)=\{x\}\), is injective，所以
\(\card{X}\le\card{\Pow(X)}\)。接着证明不存在 bijection
\(X\to\Pow(X)\)。

假设 \(f:X\to\Pow(X)\) is surjective。定义 diagonal set
\[
  T=\setbuilder{x\in X}{x\notin f(x)}.
\]
因为 \(T\subseteq X\)，所以 \(T\in\Pow(X)\)。由 surjectivity，存在
\(y\in X\) 使得 \(f(y)=T\)。现在检查 \(y\) 是否属于 \(T\)：
\[
  y\in T
  \iff y\notin f(y)
  \iff y\notin T.
\]
一个 statement 不可能与自己的 negation 等价，所以假设导致
contradiction。因此不存在 surjection \(X\to\Pow(X)\)，更不存在
bijection。于是 \(\card{X}<\card{\Pow(X)}\)。
\end{proof}

\begin{explanation}
diagonal set \(T\) 的定义故意在第 \(x\) 个位置与 \(f(x)\) 相反：若
\(x\in f(x)\)，则 \(x\notin T\)；若 \(x\notin f(x)\)，则 \(x\in T\)。
因此 \(T\) 与 list 中每一个 \(f(x)\) 至少在 \(x\) 这个 membership
question 上不同。这个机制是 diagonal argument 的核心。
使用 diagonal argument 时要先确认 list 的第 \(x\) 项本身是一个 subset of
\(X\)，这样才可以询问 ``\(x\in f(x)\) 吗''。构造出的 \(T\) 不是随意的
counterexample，而是逐项反转 membership 的 set；因此无论 list 怎样排列，
\(T\) 都会在对应 index 上逃出那一项。
\end{explanation}

\begin{theorem}[The reals are uncountable]
\[
  \card{\N}<\card{\R}.
\]
\end{theorem}

\begin{proof}
由 Cantor's theorem，
\[
  \card{\N}<\card{\Pow(\N)}.
\]
构造 injection \(\Phi:\Pow(\N)\to[0,1]\subseteq\R\)。对
\(S\subseteq\N\)，令
\[
  \Phi(S)=\sum_{n=0}^{\infty}\frac{a_n}{3^{n+1}},
  \qquad
  a_n=
  \begin{cases}
    1,&n\in S,\\
    0,&n\notin S.
  \end{cases}
\]
若 \(S\ne S'\)，取最小的 \(k\) 使得 \(a_k\ne a'_k\)。前 \(k\) 项相同，
第 \(k\) 项贡献的差的绝对值是 \(3^{-(k+1)}\)。后面所有项最多能抵消
\[
  \sum_{n=k+1}^{\infty}\frac{1}{3^{n+1}}
  =\frac{1}{2\cdot 3^{k+1}},
\]
严格小于第 \(k\) 项差。因此 \(\Phi(S)\ne\Phi(S')\)，\(\Phi\) is
injective。于是 \(\card{\Pow(\N)}\le\card{\R}\)。结合
\(\card{\N}<\card{\Pow(\N)}\)，得到 \(\card{\N}<\card{\R}\)。
\end{proof}

\begin{explanation}
这里使用 ternary digits \(0\) and \(1\)，而不是 binary digits，是为了
避免不同 expansions 产生同一个 real number 的麻烦。第一个不同 digit
造成的差大于后续 tail 的总可能抵消量，所以 encoding 是 injective。
解决从 \(\Pow(\N)\) 到 real interval 的 injection 时，可以把 subset
\(S\) 看成 infinite \(0/1\)-sequence。选择 base \(3\) 并只用 digits
\(0,1\) 或 \(0,2\)，目的是让第一个不同 digit 的影响压过所有后续 digits。
这样就不必处理 \(0.01111\ldots=0.10000\ldots\) 这类二进制表示冲突。
\end{explanation}

\begin{exerciseblock}[Worksheet 8 Exercise 3]
Let \([0,1]=\{x\in\R:0\le x\le 1\}\). Which of the following is true?
\[
  \card{\N}>\card{[0,1]},\qquad
  \card{\N}=\card{[0,1]},\qquad
  \card{\N}<\card{[0,1]}.
\]
\end{exerciseblock}

\begin{solution}
正确关系是
\[
  \card{\N}<\card{[0,1]}.
\]
由 Cantor's theorem 有 \(\card{\N}<\card{\Pow(\N)}\)。上一个 theorem 的
proof 实际构造了 injection \(\Pow(\N)\to[0,1]\)，所以
\[
  \card{\N}<\card{\Pow(\N)}\le\card{[0,1]}.
\]
如果 \(\card{\N}=\card{[0,1]}\)，则由 transitivity 得
\(\card{\Pow(\N)}\le\card{\N}\)，这会与
\(\card{\N}<\card{\Pow(\N)}\) 矛盾。因此 \(\card{\N}\ne\card{[0,1]}\)。
结合 \(\card{\N}\le\card{[0,1]}\)，得到
\(\card{\N}<\card{[0,1]}\)。
\end{solution}

\begin{explanation}
这道题的易错点是把 \([0,1]\) 的有限长度误读成有限或 countable。
cardinality 不测量 length；它只问是否存在 bijection。Cantor's theorem
说明 even the unit interval already has strictly more points than \(\N\)。
遇到选择题式的 cardinality comparison，先排除 impossible equality。
\(\N\subseteq[0,1]\) 并不成立，所以不能用 inclusion；更好的路线是使用
已经建立的 chain
\[
  \card{\N}<\card{\Pow(\N)}\leq\card{[0,1]}.
\]
一旦知道右边至少和 \(\Pow(\N)\) 一样大，就可以排除 countable 的选项。
\end{explanation}

\section{Continuum hypothesis \optional}

\begin{exerciseblock}[Lecture Notes Section 6.2 Continuum hypothesis]
State the Continuum Hypothesis and explain its role in comparing
\(\card{\N}\), intermediate cardinalities, and \(\card{\R}\).
\end{exerciseblock}

\begin{solution}
Continuum Hypothesis, abbreviated CH，断言不存在 set \(S\) 使得
\[
  \card{\N}<\card{S}<\card{\R}.
\]
换言之，如果 \(\aleph_0=\card{\N}\) 且
\(\mathfrak c=\card{\R}\)，那么 CH 说第一个 uncountable cardinal 已经是
\(\mathfrak c\)。在常见 notation \(\mathfrak c=2^{\aleph_0}\) 下，CH 常写成
\[
  2^{\aleph_0}=\aleph_1.
\]

Lecture notes 的重点是：CH 不是 usual ZFC axioms 的 theorem。若 ZFC
consistent，则在 ZFC 中加入 CH 不会产生 contradiction；在 ZFC 中加入
\(\lnot\mathrm{CH}\) 也不会产生 contradiction。Godel 证明了 CH 相对于 ZFC
的 consistency direction，Cohen 用 forcing 证明了
\(\lnot\mathrm{CH}\) 的 corresponding consistency direction。因此在本课程
中，CH 应被看作关于 cardinality 的重要 independent statement，而不是普通
proof 中可以自由调用的工具。
\end{solution}

\begin{explanation}
Cantor's theorem 给出 strict jump \(\card{\N}<\card{\Pow(\N)}\)，而 standard
encodings 把 \(\card{\Pow(\N)}\) 与 \(\card{\R}\) 识别起来。CH 问的是这两者
之间是否存在 strictly intermediate cardinality。Usual axioms alone 不能决定
答案，所以本课程中的 proof 不应假设 CH，除非题目明确允许。
理解 CH 时要分清 theorem 和 axiom extension。Cantor's theorem 已经证明
\(\R\) uncountable，但没有告诉我们 \(\card{\N}\) 与 \(\card{\R}\) 之间是否
还有 intermediate cardinality。CH 正是在回答这个缺口；independence 结果说
usual axioms 本身无法决定这个答案。
\end{explanation}

\section{Axiom of Choice and Zorn's Lemma \optional}

\begin{definition}[choice function]
设 \(\mathcal S\) 是一个 set，其 elements 本身都是 non-empty sets。
\(\mathcal S\) 的 choice function 是一个 function
\[
  c:\mathcal S\to\bigcup\mathcal S
\]
满足对每个 \(A\in\mathcal S\)，都有 \(c(A)\in A\)。
\end{definition}

\begin{theorem}[Axiom of Choice]
若 \(\mathcal S\) 是一个由 non-empty sets 组成的 set，则 \(\mathcal S\)
存在 choice function。
\end{theorem}

\begin{exerciseblock}[Lecture Notes Section 6.3 Axiom of choice and Zorn's Lemma]
Explain the Axiom of Choice, two cardinality consequences, and the statement of
Zorn's Lemma.
\end{exerciseblock}

\begin{solution}
Axiom of Choice 说：对任意由 non-empty sets 组成的 family
\(\mathcal S\)，可以同时从每个 member \(A\in\mathcal S\) 中选出一个
element。形式上，就是存在 choice function \(c\) 使
\(c(A)\in A\)。有限 family 不需要新的 axiom，因为可以逐个选择；Axiom of
Choice 处理的是无限多个 choices 且没有 uniform rule 的情况。

第一个 cardinality consequence：若 \(f:X\to Y\) is surjective，则
\(\card{Y}\le\card{X}\)。对每个 \(y\in Y\)，fiber
\[
  f^{-1}(\{y\})=\setbuilder{x\in X}{f(x)=y}
\]
是 non-empty。由 Axiom of Choice，可为每个 \(y\) 选择
\[
  g(y)\in f^{-1}(\{y\}).
\]
于是 \(g:Y\to X\) is injective：若 \(g(y)=g(y')=x\)，则
\[
  y=f(x)=y'.
\]
所以 \(\card{Y}\le\card{X}\)。这条结论可以理解为：surjection
\(X\to Y\) 说明 \(X\) 至少有足够多的 elements 来覆盖 \(Y\)，而 choice
function 把每个 \(Y\)-element 选一个 preimage，变成 injection \(Y\to X\)。

第二个 cardinality consequence：countable union of countable sets is
countable。设 \(\{A_n\}_{n\in\N}\) 是 countable sets。对每个 \(n\)，选择
surjection \(f_n:\N\to A_n\)；若 \(A_n\) 是 finite non-empty set，可以在列完
所有 elements 后重复某个 element；若 \(A_n=\emptyset\)，它不影响 union。
这里的 choice 用来一次性选择整族 enumerations \(\{f_n\}\)。定义
\[
  F:\N\times\N\to\bigcup_{n\in\N}A_n,\qquad F(n,m)=f_n(m).
\]
这个 \(F\) is surjective。因为 \(\N\times\N\) is countable，存在
surjection \(\N\to\N\times\N\)。composition 给出从 \(\N\) 到
\(\bigcup_n A_n\) 的 surjection，所以 union is countable。

Zorn's Lemma 是与 Axiom of Choice equivalent 的 order-theoretic statement。
设 \((P,\le)\) 是 non-empty partially ordered set。若每个 chain
\(C\subseteq P\) 都在 \(P\) 中有 upper bound，则 \(P\) 有 maximal element。
这里 chain 指任意两个 elements 都 comparable 的 subset；upper bound 指
\(u\in P\) 满足 \(c\le u\) for all \(c\in C\)；maximal element \(m\) 指不
存在 \(p\in P\) 使 \(m<p\)。
\end{solution}

\begin{explanation}
Axiom of Choice 把许多 local non-empty statements 合成一个 global function。
在 surjection result 中，local objects 是 fibers
\(f^{-1}(\{y\})\)；在 countable-union result 中，local objects 是每个
\(A_n\) 的 enumerations。遇到需要使用 choice 的证明时，先明确写出
``我要从哪些 non-empty sets 中各选一个 object''，再把这些 choices 组织成
function。

Zorn's Lemma 是同一原则的 order-theoretic form。它不直接选出很多
elements，而是研究 partial constructions：若任何 totally ordered family of
partial constructions 都可以合并成一个 upper bound，那么就存在一个无法再
扩大的 maximal construction。使用 Zorn 时，最后还要证明 maximal 不只是
``不能再大''，而是具有题目要求的 global property；否则可以扩张它并得到
contradiction。
\end{explanation}

\begin{reviewbox}{Zorn proof pattern}
典型 Zorn proof 有五步。第一，选择 partially ordered set \(P\)，通常是某种
partial objects，order 多数是 inclusion 或 extension。第二，验证
\(P\neq\emptyset\)，例如 empty partial object 属于 \(P\)。第三，取任意
chain \(C\)，构造 upper bound，常见做法是取 union \(\bigcup C\)，再检查它仍
满足 \(P\) 的 defining conditions。第四，引用 Zorn's Lemma 得到 maximal
object。第五，用 contradiction 解释 maximal object 为什么已经满足目标：
若还缺某个性质，就可以添加一个 piece 得到更大的 object，违背 maximality。
\end{reviewbox}

\section{Intervals}

\begin{theorem}
\[
  \card{(0,1)}=\card{\R}.
\]
\end{theorem}

\begin{proof}
定义 function
\[
  f:(0,1)\to\R,\qquad
  f(x)=\tan\bigl(\pi(x-\tfrac12)\bigr)
\]
它是 bijection。理由是：\(x-\tfrac12\) 把 \((0,1)\) bijectively 送到
\((-\tfrac12,\tfrac12)\)，乘以 \(\pi\) 把这个 interval bijectively 送到
\((-\pi/2,\pi/2)\)，而 tangent function 把
\((-\pi/2,\pi/2)\) bijectively 送到 \(\R\)。Bijections 的 composition 仍是
bijection，所以 \(\card{(0,1)}=\card{\R}\)。
\end{proof}

\begin{exerciseblock}[Worksheet 8 Exercise 4]
Let \((0,1)=\{x\in\R:0<x<1\}\). Prove that
\(\card{(0,1)}=\card{[0,1]}\).
\end{exerciseblock}

\begin{solution}
使用 Cantor--Bernstein theorem。Inclusion map
\[
  i:(0,1)\to[0,1],\qquad i(x)=x
\]
is injective，所以 \(\card{(0,1)}\le\card{[0,1]}\)。反向定义
\[
  j:[0,1]\to(0,1),\qquad j(x)=\frac{x+1}{3}.
\]
若 \(0\le x\le 1\)，则 \(1/3\le j(x)\le 2/3\)，所以 \(j(x)\in(0,1)\)。
若 \(j(x)=j(y)\)，则 \((x+1)/3=(y+1)/3\)，从而 \(x=y\)。因此 \(j\) is
injective，且 \(\card{[0,1]}\le\card{(0,1)}\)。
Cantor--Bernstein theorem gives
\[
  \card{(0,1)}=\card{[0,1]}.
\]
\end{solution}

\begin{explanation}
添加 endpoints \(0\) and \(1\) 会改变 topology and compactness，但不会改变
cardinality。关键技巧是 compression：把整个 closed interval 缩放平移到
open interval 内部的一个 smaller interval \((1/3,2/3)\)。类似题目中，若
很难写出处理 endpoints 的 bijection，就构造两个 injections，然后让
Cantor--Bernstein 负责把它们合成为 cardinality equality。
\end{explanation}

\begin{exerciseblock}[Lecture Notes Exercise 63]
Show that all intervals have the same cardinality.
\end{exerciseblock}

\begin{solution}
这句话需要采用标准的 non-degenerate interpretation。Empty intervals 和
singleton intervals 不可能与 \((0,1)\) 有相同 cardinality。对至少含有两个
points 的 non-empty real intervals，所有 usual intervals 都有 cardinality
\(\card{\R}\)。

第一，若 \(a<b\)，bounded open interval \((a,b)\) 与 \((0,1)\) 之间有
bijection
\[
  \ell:(0,1)\to(a,b),\qquad \ell(x)=a+(b-a)x.
\]
inverse 是 \(y\mapsto (y-a)/(b-a)\)，所以 \(\ell\) is bijective。

第二，bounded closed 或 half-closed interval 在 \(a<b\) 时也与
\((0,1)\) 有相同 cardinality。以 \([a,b]\) 为例，
\((a,b)\subseteq[a,b]\) 给出 injection \((a,b)\to[a,b]\)。另一个 map
\[
  [a,b]\to(a,b),\qquad x\mapsto a+\frac{b-a}{4}+\frac{x-a}{2}
\]
的 image 是 \([a+(b-a)/4,a+3(b-a)/4]\subset(a,b)\)，并且它 is injective。
由 Cantor--Bernstein，\(\card{[a,b]}=\card{(a,b)}\)。同样的 compression
也适用于 \([a,b)\) and \((a,b]\)。

第三，unbounded intervals 有 cardinality \(\card{\R}\)。例如
\[
  (a,\infty)\to\R,\qquad x\mapsto \log(x-a)
\]
is bijective；对于 \((-\infty,b)\)，可用 \(x\mapsto \log(b-x)\)，必要时再
乘以 \(-1\)，得到 left-unbounded case。Endpoints 仍可用同样的
Cantor--Bernstein compression argument 添加或移除。

因为 \((0,1)\) 与 \(\R\) bijective，所有 non-degenerate standard intervals
mutually equipotent。
\end{solution}

\begin{explanation}
这个 proof 按 interval shape 分三类：bounded open, bounded with endpoints,
and unbounded。Affine maps 处理 bounded open intervals；Cantor--Bernstein
处理 endpoints，因为 finite endpoint change 可以通过 injection 吸收到较小的
subinterval 内；logarithm 处理 rays，因为它把 endpoint 右侧的 positive
distance bijectively 送到 all real numbers。

解决类似问题时，先排除 degenerate cases，再把 interval 化到已知模型
\((0,1)\) 或 \(\R\)。如果 interval 只差 endpoints，不要强行写 explicit
bijection；compression injection 加 Cantor--Bernstein 通常更清楚。
\end{explanation}

\section{Cantor set \optional}

\begin{exerciseblock}[Lecture Notes Section 6.5 Cantor set]
Construct the Cantor set, describe it by ternary expansions, compare its length
intuition with its cardinality, and prove \(\card{C}=\card{\R}\).
\end{exerciseblock}

\begin{solution}
从
\[
  C_0=[0,1].
\]
开始。Stage \(1\) 移除 open middle third \((1/3,2/3)\)，留下
\[
  C_1=[0,1/3]\cup[2/3,1].
\]
之后每个 stage 都从前一 stage 留下的每个 closed interval 中移除 open
middle third。因此 \(C_n\) 是 \(2^n\) 个 closed intervals 的 union，每个
interval 长度为 \(3^{-n}\)。Cantor set 定义为
\[
  C=\bigcap_{n=0}^{\infty}C_n.
\]

每个 \(x\in[0,1]\) 都有 ternary expansion
\[
  x=\sum_{k=1}^{\infty}\frac{a_k}{3^k},
  \qquad a_k\in\{0,1,2\}.
\]
当某个 point 有两个 ternary expansions 时，尽量选择不以 all \(2\)'s
eventual tail 结尾的 expansion。在这个 convention 下，\(x\in C\) 当且仅当
\(x\) 有只使用 digits \(0\) and \(2\) 的 ternary expansion。理由按 stage
检查：第一次移除的 middle third 正是 first ternary digit 为 \(1\) 的
points；第 \(n\) 次移除的 middle thirds 正是前面 digits 避开 \(1\)，但第
\(n\) 个 digit 第一次等于 \(1\) 的 points。

被移除的 total length 是
\[
  \frac13+\frac{2}{9}+\frac{4}{27}+\cdots
  =
  \sum_{n=1}^{\infty}\frac{2^{n-1}}{3^n}
  =
  \frac13\sum_{k=0}^{\infty}\left(\frac23\right)^k
  =1.
\]
因此 length intuition 会说剩下的 set 很小。

现在证明 cardinality。令 \(\{0,1\}^{\N_+}\) 表示 positive integers indexed
的 infinite binary sequences。定义
\[
  F:\{0,1\}^{\N_+}\to C,\qquad
  F((s_1,s_2,\ldots))
  =
  \sum_{k=1}^{\infty}\frac{2s_k}{3^k}.
\]
这个 map 把 binary digit \(0\) 送成 ternary digit \(0\)，把 binary digit
\(1\) 送成 ternary digit \(2\)。因此 image lies in \(C\)。若两个 binary
sequences 第一次在 position \(k\) 不同，则对应 ternary expansions 在该位的
差是 \(2/3^k\)，而后续 tail 最多贡献
\[
  \sum_{j=k+1}^{\infty}\frac{2}{3^j}=\frac{1}{3^k},
\]
这个上界小于 \(2/3^k\)。所以 \(F\) is injective。反过来，每个
point of \(C\) 都有 chosen ternary expansion using only \(0\) and \(2\)，把每
个 ternary digit 除以 \(2\) 就得到一个 binary sequence，并且它映到该 point。
因此 \(F\) is surjective。于是
\[
  \card{C}=\card{\{0,1\}^{\N_+}}=\card{\Pow(\N)}=\card{\R}.
\]
\end{solution}

\begin{explanation}
Cantor set 把两种 size 概念分开。被移除的 total length 是 \(1\)，所以在
measure language 中它有 length \(0\)。但 cardinality 计算的是可能的
infinite digit sequences。\(0/2\)-ternary sequences 与 binary sequences 一样
多，而 binary sequences 等价于 subsets of \(\N\)，cardinality 为
\(\card{\Pow(\N)}=\card{\R}\)。

处理 Cantor set 题时，先问问题属于哪一种 size：若问 length，就求 removed
middle thirds 的 geometric series；若问 membership，就看 ternary digits
是否出现 \(1\)；若问 cardinality，就把 \(0/2\)-ternary digits 编码成 binary
sequences，再连接到 \(\Pow(\N)\)。
\end{explanation}

\section{Density \optional}

\begin{definition}[dense subset of \(\R\)]
Subset \(S\subseteq\R\) is dense in \(\R\) 的意思是：对每个 \(r\in\R\) 和每个
\(\eps>0\)，都存在 \(s\in S\) 使得
\[
  |r-s|<\eps.
\]
\end{definition}

\begin{exerciseblock}[Lecture Notes Section 6.6 Density]
Explain density, prove that \(\Z\) is not dense in \(\R\), prove that
\(\Q\) is dense in \(\R\), and define dense in a subset.
\end{exerciseblock}

\begin{solution}
Density 问的是 \(S\) 的 elements 能否用 arbitrarily small error 逼近每个
real number。它不是 cardinality notion。

Integers are not dense in \(\R\)。取 \(r=1/2\) and \(\eps=1/4\)。对任意
\(n\in\Z\)，数 \(n-1/2\) 是 half-integer，所以
\[
  |n-1/2|\ge 1/2>1/4.
\]
因此没有 integer 落在 \(1/2\) 的 distance \(1/4\) 以内，所以 \(\Z\) is not
dense。

Rationals are dense in \(\R\)。取任意 \(r\in\R\) and \(\eps>0\)。由
Archimedean property，选择 \(n\in\N\) with \(n>1/\eps\)，于是
\(1/n<\eps\)。再选择 integer \(m\) 满足
\[
  m\le nr<m+1.
\]
令 \(q=m/n\in\Q\)，则
\[
  0\le r-q=r-\frac{m}{n}<\frac1n<\eps.
\]
因此 \(|r-q|<\eps\)，所以 \(\Q\) is dense in \(\R\)。

若 \(T\subseteq\R\)，则 \(S\subseteq T\) is dense in \(T\) 的意思是：对每个
\(t\in T\) 和每个 \(\eps>0\)，存在 \(s\in S\) 使得
\[
  |t-s|<\eps.
\]
\end{solution}

\begin{explanation}
\(\Q\) is countable but dense; the Cantor set is uncountable but has empty
interior and length \(0\)。These examples show why density cannot be inferred
from cardinality. Density depends on the order and distance inherited from
\(\R\)，not only on how many elements a set has.
证明某个 set 不 dense，只需找到一个 point 和一个 positive radius，使对应
open interval 完全避开该 set。证明 dense，则要从任意 \(r\) and arbitrary
\(\eps\) 出发构造 approximating element。对 \(\Q\)，denominator \(n\) 控制
mesh size \(1/n\)，integer \(m\) 选择落在 \(nr\) 左侧的 grid point。
\end{explanation}

\begin{exerciseblock}[Lecture Notes Exercise 64]
Prove the Archimedean property for \(\R\): for any \(x\in\R\) with \(x>0\),
there exists \(n\in\N\) such that \(n>x\).
\end{exerciseblock}

\begin{solution}
我们用 \(\R\) 的 least upper bound property 证明。假设存在 \(x>0\)，使得对
每个 \(n\in\N\) 都有 \(n\le x\)。那么 \(\N\) 在 \(\R\) 中 bounded above。令
\[
  \alpha=\sup\N.
\]
因为 \(\alpha\) 是 least upper bound，\(\alpha-1\) 不是 \(\N\) 的 upper
bound。因此存在 \(n\in\N\) 使得
\[
  n>\alpha-1.
\]
两边加 \(1\) 得到 \(n+1>\alpha\)。但 \(n+1\in\N\)，这与 \(\alpha\) 是
\(\N\) 的 upper bound 矛盾。因此 \(\N\) 在 \(\R\) 中 not bounded above。
于是对每个 \(x>0\)，都存在 \(n\in\N\) with \(n>x\)。
\end{solution}

\begin{explanation}
这个 proof 把 Archimedean property 转换成 boundedness statement。若某个
positive \(x\) 大到压住所有 natural numbers，则 \(\N\) 会有 supremum
\(\alpha\)。Supremum 的定义说任何小于 \(\alpha\) 的数都不是 upper bound，
特别是 \(\alpha-1\)。于是存在 natural number \(n>\alpha-1\)，而 \(n+1\)
超过 \(\alpha\)，矛盾。

以后使用 Archimedean property 时，常见目标是制造很小的 mesh：给定
\(\eps>0\)，选 \(n>1/\eps\)，就得到 \(1/n<\eps\)。Density of \(\Q\) 的证明
正是这个模式。
\end{explanation}

\section{Well-ordering \optional}

\begin{definition}[well-ordered set]
设 \((X,\le)\) 是 totally ordered set。若每个 non-empty subset
\(S\subseteq X\) 都有 minimum element，则称 \((X,\le)\) is well-ordered。
\end{definition}

\begin{exerciseblock}[Lecture Notes Section 6.7 Well-ordering]
Explain well-ordering, prove the basic examples and non-examples, show that
countable sets can be well-ordered, and state the Well-Ordering Theorem.
\end{exerciseblock}

\begin{solution}
Well-ordering 比 total order 更强。Total order 只要求任意两个 elements 可以
比较；well-ordering 还要求每个 non-empty subset 都有 first element。

每个 finite ordinal \(n=\{0,1,\ldots,n-1\}\) 在 usual order 下
well-ordered。取 non-empty \(S\subseteq n\)。因为 \(S\) finite，可以把它的
elements 看成小于 \(n\) 的 natural numbers；在有限多个 indices 中存在最小
index，对应 element 就是 \(S\) 的 minimum。

\((\N,\le)\) is well-ordered。取 non-empty \(S\subseteq\N\)。假设 \(S\)
没有 minimum。我们用 induction 证明没有 \(n\in\N\) 属于 \(S\)。当
\(n=0\) 时，若 \(0\in S\)，则 \(0\) 会是 \(S\) 的 minimum。Induction step：
假设没有 \(k<n\) 属于 \(S\)。若 \(n\in S\)，因为没有更小的 natural number
位于 \(S\)，所以 \(n\) 会是 \(S\) 的 minimum。这与假设矛盾。因此
\(n\notin S\)。由 induction，\(S=\emptyset\)，与 \(S\) non-empty 矛盾。
所以 \(S\) has a minimum。

\((\Z,\le)\) is not well-ordered。\(\Z\) 这个 subset 本身没有 minimum：
对任意 \(z\in\Z\)，integer \(z-1\) 也在 \(\Z\) 中且满足 \(z-1<z\)。

\((\Q^+,\le)\) is not well-ordered。\(\Q^+\) 这个 subset 本身没有 minimum：
对任意 \(q\in\Q^+\)，rational number \(q/2\) 也在 \(\Q^+\) 中且满足
\(q/2<q\)。

每个 countable set 都可以被 well-ordered。若 \(X\) finite，写
\(X=\{x_0,\ldots,x_{n-1}\}\)，并定义 \(x_i\le_X x_j\) iff \(i\le j\)。
每个 non-empty subset 都有 smallest index 对应的 element。若 \(X\) is
countably infinite，选择 bijection \(f:\N\to X\)，定义
\[
  x\le_X y
  \quad\text{iff}\quad
  f^{-1}(x)\le f^{-1}(y)\text{ in }\N.
\]
对任意 non-empty \(S\subseteq X\)，preimage \(f^{-1}(S)\subseteq\N\) is
non-empty，因此有 minimum \(m\)。于是 \(f(m)\) 是 \(S\) 在 \(\le_X\) 下的
minimum。

Well-Ordering Theorem 断言 every set can be well-ordered。它与 Axiom of
Choice equivalent。一个方向较短：若每个 set 都可以被 well-ordered，且
\(\mathcal S\) 是 non-empty sets 的 family，则 well-order
\(\bigcup\mathcal S\)，并从每个 \(A\in\mathcal S\) 中选它在该 well-ordering
下的 minimum element。反方向，从 Axiom of Choice 推出 every set can be
well-ordered，需要 transfinite recursion：不断从 remaining non-empty subset
中选择 next element，直到所有 elements 都被选入 order。
\end{solution}

\begin{explanation}
Well-ordering 关心的是所有 non-empty subsets 是否都有 first element，而不是
某个 set 看起来是否排成一行。Usual order on \(\Z\) 失败，因为总能向左移动；
usual order on \(\Q^+\) 失败，因为总能把 positive rational 减半。Countable
set 可以通过 enumeration 把 \(\N\) 的 usual well-ordering transport 过去。

做 well-ordering 题时，证明 positive example 要从 arbitrary non-empty
subset 出发找 minimum；证明 negative example 只需展示一个 non-empty subset
没有 minimum。不要只说 order 没有 first element，要指出对每个 candidate
都能在同一 subset 中找到更小 element。
\end{explanation}

\section{Review checklist}

\begin{itemize}
  \item 证明 equal cardinality 时，构造 bijection，或构造两个 injections 再用
  Cantor--Bernstein theorem。
  \item 证明 \(\N\times\N\) 这类 product countable 时，用 diagonal
  enumeration 或 Cantor pairing。
  \item 证明 uncountability 时，用 Cantor's theorem，或用 diagonal argument
  从任意 proposed list 中构造漏掉的 object。
  \item 比较 intervals 时，用 affine bijections, compression injections,
  and Cantor--Bernstein theorem。
  \item 使用 Axiom of Choice 时，先指出需要 simultaneous choices 的
  non-empty sets family。
  \item 使用 Zorn's Lemma 时，先确定 partially ordered set，证明每个 chain
  有 upper bound，再解释 maximality 如何给出目标结论。
  \item 讨论 density 或 well-ordering 时，把 order or metric structure 与
  cardinality 分开。
\end{itemize}
